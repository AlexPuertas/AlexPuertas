## 🚀 Proyectos destacados

### [Scheduly](https://github.com/AlexPuertas/Scheduly)
> Plataforma SaaS web de gestión de citas y turnos.

Dos roles (EMPRESA / CLIENTE) con autenticación y control de acceso por rol mediante **Spring Security**. Las empresas publican su disponibilidad horaria; los clientes reservan y cancelan citas en tiempo real.

`Java` `Spring Boot 3.2` `Spring Data JPA` `Spring Security` `Thymeleaf` `MySQL`

---

### Web e Intranet — Grupo de Astrofísica (UGR)
> Sitio web público + intranet para un grupo de investigación de la Universidad de Granada (feb–may 2026).

Frontend desacoplado en **Next.js + TypeScript**; API en **PHP** con configuración CORS y enrutamiento `.htaccess`. Estética glassmorphism oscuro, componentes modularizados, páginas de Publicaciones y Divulgación.

`Next.js` `React` `TypeScript` `PHP` `API REST`

*(Repositorio privado — código perteneciente a la UGR)*

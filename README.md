### [Scheduly](https://github.com/AlexPuertas/Scheduly)
> Plataforma SaaS de gestión de turnos y reservas para hostelería · Proyecto propio

Diseño y desarrollo individual de una plataforma SaaS multiempresa. Backend completo con **Java y Spring Boot** (API REST), con autenticación y autorización por roles (**empresa** y **cliente**) mediante **Spring Security**. Persistencia con **JPA/Hibernate** sobre **MySQL**, operaciones CRUD completas y gestión del proyecto con **Maven**. Interfaz en HTML y CSS.

`Java` `Spring Boot` `Spring Security` `JPA/Hibernate` `Maven` `MySQL` `SQL` `HTML` `CSS` `Git`

### Generador de preguntas con IA
> Proyecto académico · Práctica UD1 — Explotación y despliegue

Miniaplicación de una sola pantalla en la que el usuario pega un texto y la **API de OpenAI** genera preguntas de repaso de forma automática. Desplegada en **Vercel** (con autenticación **Clerk**) y en un contenedor **Docker** sobre **AWS EC2**.

🔗 [Demo](https://proyecto-explotacion-y-despliegue-d.vercel.app) · [Repositorio](https://github.com/ExplotacionDeServicios/Proyecto-Explotacion-y-despliegue-de-una-aplicacion-con-IA)

`OpenAI API` `Docker` `AWS EC2` `Vercel` `Clerk` `Git` `GitHub`

### Analizador de equipos Pokémon
> Proyecto personal · En desarrollo

Aplicación web en **Laravel** que analiza equipos de 6 Pokémon (formato Showdown, Singles): debilidades defensivas y cobertura ofensiva frente a los 18 tipos. Incluye un parser propio del formato Showdown y un modelo de dominio (tipos, movimientos, Pokémon, equipo), con **34 tests automatizados**.

`PHP` `Laravel` `Git` `GitHub`
